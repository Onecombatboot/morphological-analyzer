BLIND ADJUDICATION WORKSHEET

For each item decide, using CRITERION.md v2 only:
  Y  some real configuration could contain both
  N  no possible configuration instantiates both
The test is "does this combination occur?", never "does it work well?".
Ineffective, unwise or badly designed is still Y.
If N, name the clause on each side that makes it impossible.

Write answers as "<number>: <Y|N>" and, for N, a following line
"<number>! <requires clause> >< <blocked clause>".
