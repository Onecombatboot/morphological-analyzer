DOMAIN: drought and water rationing
GROUP: resource management
PARAM: SUPPLY SOURCE
- Surface reservoir storage :: rainfall captured behind a dam :: visible declining storage, months of warning, vulnerable to evaporation
- Confined groundwater aquifer :: boreholes into a deep formation :: buffered against a single dry season, recharge over decades, no visible indicator to the public
- River abstraction :: a licence to take flow directly :: immediate response to rainfall, competition with ecological flow, no storage buffer at all
- Desalination plant :: coastal intake and very large electrical supply :: independence from rainfall entirely, high unit cost, months to commission
PARAM: DEMAND SECTOR
- Household consumption :: connected domestic properties :: politically sensitive, modest total volume, responsive to tariffs and messaging
- Irrigated agriculture :: farms holding abstraction rights :: the largest volume by far, seasonal timing, livelihood consequences
- Industrial process water :: plants with process dependence :: continuous demand, employment consequences, some recycling possible
- Power station cooling :: thermal generation needing cooling water :: non-substitutable within the plant, loss of generation if curtailed
PARAM: RATIONING MEASURE
- Tariff increase :: a metered supply and a billing relationship :: demand reduction through price, regressive impact, no effect on unmetered users
- Rota supply by zone :: network valves and a schedule :: enforced volume reduction, contamination risk on repressurisation
- Ban on non-essential use :: an enforceable legal restriction :: rapid modest saving, dependence on compliance
- Emergency inter-basin transfer :: an existing pipeline or canal to another basin :: import of volume, transfer of the shortage elsewhere
PARAM: OUTCOME
- Shortage averted :: demand reduced within available supply :: no service failure
- Supply interruption by zone :: demand still exceeding supply :: intermittent service, public health risk from contamination
- Agricultural production lost :: irrigation curtailed for a season :: economic loss concentrated on farmers
- Total supply failure :: source exhausted with no alternative :: emergency tankering, mass relocation

DOMAIN: desert locust outbreak
GROUP: agriculture
PARAM: INFESTATION STAGE
- Solitarious population :: low density in the recession area :: no crop threat, no gregarious behaviour, detectable only by dedicated survey
- Hopper bands on the ground :: gregarisation after good rains :: flightless and concentrated, highly treatable, a short window before fledging
- Immature swarm in flight :: fledged adults forming a swarm :: movement of a hundred kilometres a day, unpredictable settling, no egg laying yet
- Mature swarm laying eggs :: sexual maturation after rainfall :: the next generation established, laying sites dispersed over a wide area
PARAM: SURVEY CAPABILITY
- Ground survey teams :: vehicles and trained scouts with access :: accurate stage and density data, limited to accessible ground
- Satellite greenness imagery :: cloud-free imagery and analysis :: identification of areas that may become breeding habitat, no direct sight of any insect
- Aerial reconnaissance :: light aircraft on task :: rapid coverage of large areas, detection of swarms rather than hoppers
- No survey access :: conflict or insecurity closing the area :: no information from that territory at all
PARAM: CONTROL METHOD
- Ground vehicle spraying :: road access to the target band :: precise treatment of hopper bands, very low output per day
- Aerial ultra-low-volume spraying :: aircraft, an airstrip and a located target :: treatment of large swarms, dependence on knowing where the target is
- Biopesticide application :: acceptance of a slower kill and warm conditions :: no harm to non-target species, effect over one to two weeks
- No intervention :: nothing :: no cost, full development to the next stage
PARAM: OUTCOME
- Outbreak contained locally :: treatment during the hopper stage :: minimal crop loss, no regional spread
- Regional upsurge :: multiple generations across countries :: sustained multi-country campaign, major funding requirement
- Crop loss in one season :: swarms reaching cultivated land :: food security emergency, no permanent change
- Plague across the range :: continuous breeding over years :: transboundary emergency, years to bring under control

DOMAIN: undersea cable damage
GROUP: infrastructure
PARAM: DAMAGE CAUSE
- Fishing trawl or anchor :: a vessel working over the cable route :: shallow water damage, an identifiable vessel track, the commonest cause by far
- Submarine landslide :: seabed instability on a slope :: multiple cables cut simultaneously, deep water, no responsible party
- Deliberate cutting by a state actor :: a vessel or vehicle capable of reaching the cable :: precise simultaneous cuts, deniability, no accidental signature
- Equipment failure in a repeater :: an electronic fault in the wet plant :: no physical break in the cable, capacity lost on some fibres only
PARAM: ROUTE REDUNDANCY
- Single cable serving the territory :: one physical path :: total loss of connectivity on any break, no alternative at all
- Multiple cables on the same corridor :: several cables sharing a seabed route :: apparent redundancy, common-mode failure from one seabed event
- Geographically diverse cables :: paths separated by hundreds of kilometres :: genuine redundancy against any local event
- Satellite backup available :: contracted capacity on orbit :: continuity of essential traffic, a small fraction of cable capacity
PARAM: DETECTION AND LOCATION
- Optical time-domain reflectometry :: access to the fibre from a landing station :: distance to the fault along the cable, no cause information
- Traffic monitoring at the landing station :: network telemetry :: immediate awareness of loss, no location
- Vessel tracking correlation :: an automatic identification system record :: identification of a vessel over the fault at the time, only for surface vessels
- Repair ship survey :: a cable ship on site :: definitive location and cause, days to weeks to arrive
PARAM: SERVICE CONSEQUENCE
- No user impact :: capacity absorbed by other paths :: no consequence
- Degraded capacity :: reduced bandwidth on surviving paths :: congestion and latency, service continues
- Complete outage for the territory :: all paths lost :: national-scale disconnection
- Financial market disruption :: latency-sensitive traffic rerouted :: trading impact, measurable economic cost

DOMAIN: satellite navigation denial affecting transport
GROUP: infrastructure
PARAM: INTERFERENCE TYPE
- Broadband noise jamming :: a transmitter raising the noise floor :: complete loss of lock, obvious failure, easily geolocated
- Meaconing rebroadcast :: a receiver and a delayed retransmission :: a plausible but wrong position, no loss of lock at all
- Spoofed constellation signal :: knowledge of the signal structure and timing :: a controlled false position, the receiver reporting full confidence
- Solar radio burst :: natural emission from the sun :: brief hemisphere-wide degradation, no attributable actor
PARAM: AFFECTED USER
- Commercial aviation :: aircraft using satellite-based approach procedures :: reversion to conventional navigation aids, crew trained for the failure
- Maritime navigation in a strait :: vessels in a confined channel :: very little sea room, radar and visual fixing available
- Road freight telematics :: fleets depending on position reporting :: no safety consequence, commercial and regulatory disruption
- Timing for the power grid :: substations using satellite time :: protection and synchrophasor errors, no positioning involved
PARAM: RESILIENCE MEASURE
- Inertial navigation backup :: an installed inertial unit :: continued navigation with drifting accuracy, no dependence on any signal
- Terrestrial radio navigation :: a ground transmitter network in service :: independent position fixing, coarse accuracy
- Holdover oscillator :: a stable local clock :: timing maintained for hours to days, no positioning benefit whatsoever
- Nothing but the satellite signal :: a single-source receiver :: total dependence, immediate loss on any interference
PARAM: CONSEQUENCE
- Detected and disregarded :: the user recognising bad data :: no operational effect
- Reversion to a backup method :: an available alternative :: reduced accuracy, operations continue
- Operations suspended :: no acceptable alternative :: delay and economic cost, safety preserved
- Position error acted upon :: false data trusted and used :: grounding, airspace infringement or protection maloperation
