DOMAIN: mass casualty triage
GROUP: emergency response
PARAM: INCIDENT MECHANISM
- Blast in a confined space :: an explosive device in an enclosed structure :: many patients with blast lung and penetrating injury, structural collapse alongside
- Multi-vehicle collision :: a high-speed motorway pile-up :: blunt trauma and entrapment, casualties spread along a corridor
- Chemical exposure at a plant :: a toxic release reaching people :: contamination of every casualty, responders at risk until decontamination
- Building collapse after an earthquake :: structural failure with people inside :: crush injury, casualties released over hours to days
PARAM: TRIAGE METHOD
- Sieve at the point of injury :: responders reaching the casualties :: rapid sorting on physiology alone, no diagnosis
- Sort at a casualty clearing station :: a secured area and clinical staff :: measured physiological scoring, delays first definitive care
- Reverse triage :: overwhelming numbers relative to capacity :: treatment of those most likely to survive, expectant category applied
- No formal triage :: casualties self-presenting to hospitals :: arrival in order of mobility rather than severity, the worst arriving last
PARAM: TRANSPORT CONSTRAINT
- Ample ambulance capacity :: a dense urban service :: everyone moved promptly, hospital load the limiting factor
- Single access route :: one road in and out :: convoy movement only, arrival in batches
- Helicopter only :: no ground access to the site :: two patients at a time, weather dependence
- Casualties must walk out :: no vehicle access whatsoever :: only ambulant casualties leave, the immobile remain on site
PARAM: RECEIVING CAPACITY
- Major trauma centre available :: a centre within transport time :: definitive surgical care, all specialties present
- District general hospital only :: a local hospital without trauma specialisation :: stabilisation and transfer, limited surgical capacity
- Field hospital established :: deployable clinical capability on site :: damage control surgery near the scene, no intensive care beyond hours
- All hospitals at capacity :: a saturated regional system :: no receiving facility, care delivered where the patient lies

DOMAIN: tsunami warning and evacuation
GROUP: natural hazard
PARAM: SOURCE EVENT
- Distant subduction earthquake :: a great earthquake across an ocean basin :: hours of travel time, confident modelling, no local ground shaking
- Local offshore earthquake :: a rupture close to the coast :: minutes of travel time, felt ground shaking as the only warning
- Submarine landslide :: slope failure with or without an earthquake :: no seismic signature proportionate to the wave, very localised run-up
- Volcanic flank collapse :: a coastal edifice failing into the sea :: extreme local run-up, no useful precursor
PARAM: WARNING CHANNEL
- Basin-wide warning centre :: seismic and sea-level networks across the basin :: authoritative bulletins within minutes, only for seismically generated waves
- Coastal siren network :: installed sirens and a trigger authority :: immediate alerting of a defined coastal strip, nothing to anyone indoors or inland
- Cell broadcast to handsets :: a functioning mobile network :: reach of everyone carrying a handset, failure if the network is down
- Natural warning only :: people recognising shaking or sea withdrawal :: no institutional latency at all, dependence on public knowledge
PARAM: EXPOSED COMMUNITY
- Dense coastal city :: high-rise construction on a low coastal plain :: vertical evacuation feasible, very large exposed population
- Low-lying fishing village :: single-storey buildings at sea level :: no vertical refuge whatsoever, short distance to high ground
- Resort with transient visitors :: a population unfamiliar with the coast :: no local knowledge, no idea where high ground lies
- Port and industrial zone :: infrastructure with few residents :: economic exposure, few lives at risk
PARAM: EVACUATION RESPONSE
- Horizontal movement inland :: usable routes and sufficient time :: removal from the inundation zone entirely
- Vertical evacuation in place :: engineered buildings of sufficient height :: survival above the wave, no movement needed
- Shelter without evacuation :: a belief that the site is safe :: no movement, total dependence on that belief being correct
- Spontaneous flight :: no plan and no direction :: movement without coordination, congestion on any route

DOMAIN: avalanche risk management
GROUP: natural hazard
PARAM: SNOWPACK PROBLEM
- Persistent weak layer :: a buried facet or surface hoar layer :: failure propagating far from the trigger point, instability lasting weeks
- Wind slab on a lee aspect :: transported snow deposited on a slope :: a stiff slab over softer snow, confined to specific aspects, days of instability
- Wet snow instability :: melt water percolating through the pack :: predictable daily timing, slow-moving heavy debris
- Cornice collapse :: an overhanging mass at a ridge :: a large trigger arriving without any skier action, hazard only directly below
PARAM: TRIGGER
- Skier or rider on the slope :: a person on the start zone :: a localised load, avoidable by route choice
- Explosive control from a helicopter :: an aircraft and an operator :: deliberate release at a chosen time, no exposure of any person
- Natural release without any trigger :: loading or warming beyond stability :: timing outside anyone control, occurring whether or not people are present
- Snow groomer or machine :: a vehicle working the slope :: a very large load applied on a known schedule
PARAM: EXPOSED ELEMENT
- Marked piste inside a resort :: a controlled area open to the public :: many people, an operator with a duty of care, control work possible
- Backcountry touring route :: uncontrolled terrain used by touring parties :: small self-reliant groups, no control work of any kind
- Mountain road below a path :: a transport corridor crossing runout zones :: vehicles briefly exposed, closure feasible
- Village in a runout zone :: permanent buildings within the historic extent :: no possibility of evacuation at short notice, defence structures needed
PARAM: MITIGATION
- Closure of the terrain :: an authority able to exclude people :: complete removal of exposure, economic cost
- Explosive avalanche control :: a stable weather window and access to the start zone :: release under controlled conditions, no effect on unstable layers deeper than the charge
- Snow supporting structures :: permanent works in the start zone :: prevention of release at all, decades to build and very high cost
- Forecast and advisory only :: an observation network and a publication channel :: information for decision makers, no physical effect whatsoever
EXCL: SNOWPACK PROBLEM|TRIGGER

DOMAIN: urban earthquake collapse rescue
GROUP: emergency response
PARAM: COLLAPSE PATTERN
- Pancake collapse of floor slabs :: slabs falling flat onto one another :: almost no void space, very low survival probability, heavy lifting required
- Lean-to void formation :: a slab coming to rest against a wall :: survivable voids along one edge, accessible from the standing side
- Soft-storey failure :: a weak ground floor crushing :: upper floors intact and occupied, the void confined to one level
- Unreinforced masonry disintegration :: brickwork losing coherence :: shallow burial in rubble, casualties reachable by hand
PARAM: DETECTION TECHNIQUE
- Acoustic listening devices :: a quiet site and a conscious casualty :: location of anyone able to make noise, defeated by ambient noise
- Search dogs :: a trained dog and a workable surface :: rapid indication of living casualties, no depth or precise position
- Thermal and optical cameras on poles :: an existing void to insert into :: visual confirmation inside a void, nothing through solid material
- Structural survey only :: engineers assessing from outside :: identification of likely void locations, no confirmation anyone is alive
PARAM: EXTRICATION METHOD
- Selective debris removal by hand :: shallow burial and enough responders :: no risk of further collapse, very slow for deep casualties
- Breaching and breaking concrete :: powered tools and a stable slab :: access through a slab to a known void, vibration risk to the casualty
- Heavy lifting with cranes :: crane access and a stable footing :: removal of large elements, uncontrolled shifting of what remains
- Shoring then tunnelling :: timber or hydraulic shoring and trained crews :: a protected route to a deep casualty, many hours per casualty
PARAM: TIME SINCE COLLAPSE
- First six hours :: an immediate response :: high survival probability, most live rescues occur here
- One to three days :: a sustained international response :: declining survivability, specialist teams arriving
- Beyond one week :: prolonged operations :: recovery rather than rescue, transition to demolition
