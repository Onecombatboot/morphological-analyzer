DOMAIN: research misconduct investigation
GROUP: academic
PARAM: ALLEGATION TYPE
- Image duplication in figures :: published figures available to compare :: objective evidence in the paper itself, no need for lab records
- Fabricated data set :: results reported that were never collected :: reliance on raw records to prove, denial difficult to disprove without them
- Plagiarism of text :: an earlier source to compare against :: mechanical detection, no scientific judgement required
- Authorship dispute :: disagreement among collaborators :: no question about the validity of the results, a matter of credit only
PARAM: EVIDENCE SOURCE
- Original laboratory notebooks :: contemporaneous records retained :: verification of what was actually done, dating of the work
- Raw instrument files :: an instrument archive with timestamps :: independent confirmation of acquisition, resistance to later alteration
- Published record alone :: the paper as issued :: comparison across figures and papers, no insight into the underlying work
- Records destroyed or unavailable :: retention periods expired or files lost :: no primary material of any kind, reliance on testimony
PARAM: PROCESS STAGE
- Confidential inquiry :: an allegation received and assessed :: a decision whether to proceed, no findings published
- Full investigation panel :: a formal panel convened :: witnesses heard and a finding made, months of process
- Journal-led correction process :: an editor acting on concerns :: correction or retraction of the literature, no employment consequence
- Case closed without inquiry :: an allegation judged unfounded at screening :: no investigation held, no record beyond the file
PARAM: RESOLUTION
- Retraction and dismissal :: misconduct found and proven :: the paper withdrawn, employment terminated
- Correction of the literature :: an error established without intent :: the record repaired, no misconduct finding
- Allegation not upheld :: insufficient evidence to find misconduct :: no action against the researcher, lingering suspicion
- Unresolved and abandoned :: a respondent who leaves the institution :: no finding of any kind, the literature left uncorrected

GROUP: resource management
PARAM: DEPOSIT TYPE

- Cobalt crusts on a seamount :: a hard substrate on a steep flank :: ore bonded to the rock beneath, difficult separation
- Shallow shelf placer :: unconsolidated sediment in coastal water :: conventional dredging sufficient, no deep water technology needed
PARAM: JURISDICTION
- The Area beyond national jurisdiction :: a sponsoring state and an international licence :: a common heritage regime, international oversight

- Territorial sea :: full coastal state sovereignty :: complete domestic control, close proximity to inhabited coast
- Disputed maritime boundary :: overlapping claims by two states :: no settled authority to license, exposure to protest and arrest
PARAM: EXTRACTION METHOD

- Cutter head on hard substrate :: a rock cutting head and station keeping :: removal of consolidated ore, destruction of the substrate itself
