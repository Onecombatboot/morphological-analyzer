DOMAIN: commercial aircraft maintenance defect
GROUP: aviation
PARAM: DEFECT TYPE
- Structural fatigue crack :: cycles accumulated on the airframe :: growth over time, detection only by deliberate inspection
- Engine component failure :: a part reaching its life limit :: loss of thrust, a possible uncontained release
- Avionics software fault :: a latent coding defect :: erroneous indications, no physical wear anywhere
- Corrosion in a hidden area :: moisture ingress over years :: strength lost where no one looks, discovery only on deep inspection
PARAM: DETECTION MEANS
- Line check before flight :: a walkaround and a few minutes :: gross external defects found, nothing internal seen
- Scheduled heavy maintenance :: the aircraft out of service for weeks :: structure opened and inspected, a very high cost
- Onboard monitoring system :: sensors and a data link :: continuous trend data, only what is instrumented
- Defect reported by the crew :: a symptom noticed in flight :: real operational evidence, only after it has manifested
PARAM: OPERATIONAL PRESSURE
- Aircraft grounded pending fix :: a decision to stop flying it :: the aircraft not flown at all, no revenue earned
- Deferred under the minimum equipment list :: an allowable deferral :: continued service with limitations, a fixed time to repair
- Peak season with no spare aircraft :: full utilisation planned :: strong pressure to keep flying, cancellations if grounded
- Aircraft due for retirement :: an airframe leaving the fleet shortly :: reluctance to invest in repair, an economic write-off possible
PARAM: SAFETY OUTCOME
- Defect rectified before flight :: parts and engineers available :: airworthiness restored, a delay only
- In-flight event with safe landing :: a failure managed by the crew :: an occurrence report, the aircraft recovered
- Accident with hull loss :: a failure beyond the crew's control :: fatalities possible, a formal investigation
- Defect never found at all :: no inspection ever reaching it :: latent risk carried, no record of any kind

DOMAIN: art market provenance dispute
GROUP: heritage
PARAM: OBJECT STATUS
- Documented unbroken provenance :: records covering every owner :: confident attribution and title, a premium price
- Gap in the ownership record :: years unaccounted for :: suspicion of wartime looting, a discount and slow sale
- Known forgery exposed :: technical analysis proving it modern :: no artistic value at all, a criminal question
- Recently excavated antiquity :: an object with no collecting history :: near-certain illicit export, no lawful market
PARAM: EVIDENCE AVAILABLE
- Scientific dating of materials :: a laboratory and a sample :: an objective date range for the materials, no evidence about authorship
- Archival ownership documents :: surviving papers and access to them :: a chain of title, vulnerability to forged paperwork
- Connoisseurship judgement :: an acknowledged expert in the artist :: an attribution opinion, no objective test
- No documentation whatsoever :: nothing surviving or ever created :: no chain of title available, reliance on the object alone
PARAM: CLAIMANT
- Heirs of a dispossessed owner :: proof of the original ownership :: a restitution claim, strong moral weight
- Source country authority :: a national patrimony law :: a state demand for return, diplomatic pressure
- Defrauded purchaser :: a sale contract and payment :: a civil claim against the seller, no claim to the object itself
- No claimant at all :: nobody asserting a competing right :: undisputed possession, a free sale
PARAM: RESOLUTION
- Sale proceeds at full value :: clear title and no dispute :: the object transferred, the price realised
- Restitution to the claimant :: a claim accepted or ordered :: the object handed over, compensation sometimes paid
- Object withdrawn from sale :: doubt sufficient to stop the lot :: no transaction, the object returned to the consignor
- Object seized by authorities :: a criminal or export offence :: possession lost entirely, prosecution possible
