DOMAIN: bank liquidity crisis
GROUP: finance
PARAM: TRIGGER
- Credit loss on the asset book :: borrowers defaulting in size :: solvency question rather than liquidity, losses realised over quarters
- Interest rate mark-to-market loss :: rates rising against a long bond portfolio :: unrealised loss crystallised only if assets are sold, no credit deterioration at all
- Deposit flight from social media rumour :: a coordinated loss of confidence :: outflow within hours, no change in asset quality whatsoever
- Wholesale funding market closure :: counterparties refusing to roll funding :: no retail visibility, refinancing failure at maturity
PARAM: FUNDING PROFILE
- Retail insured deposits :: balances within the guarantee limit :: very sticky, protected depositors with no incentive to run
- Large uninsured corporate deposits :: balances far above any guarantee :: highly mobile, concentrated among few holders
- Short-term wholesale borrowing :: repo and commercial paper :: repriced or withdrawn at every maturity, no depositor protection concept
- Long-dated covered bonds :: secured term funding :: no early withdrawal possible, no run risk at all
PARAM: LIQUIDITY SOURCE
- High-quality liquid asset buffer :: unencumbered government securities :: immediate monetisation, loss realised if sold below cost
- Central bank discount window :: eligible collateral and willingness to be seen using it :: large and immediate, stigma risk if disclosed
- Emergency asset sale :: a buyer for the portfolio :: cash raised, crystallisation of losses and signalling of distress
- Acquisition by a stronger bank :: a willing acquirer and regulatory approval :: complete resolution, loss of the institution
PARAM: OUTCOME
- Stabilised without intervention :: outflow ceasing on its own :: no public cost, reputational damage only
- Central bank support facility :: liquidity provided against collateral :: institution survives, moral hazard debate
- Resolution and transfer of deposits :: a resolution authority acting over a weekend :: depositors made whole, shareholders wiped out
- Disorderly failure :: no buyer and no facility :: depositor loss, contagion to peers

DOMAIN: crisis disinformation management
GROUP: information
PARAM: FALSE CLAIM TYPE
- Fabricated casualty figures :: an invented number presented as official :: directly checkable against records, quickly refutable with data
- Manipulated video of an event :: editing or synthesis of footage :: emotionally compelling, forensic analysis needed rather than a simple check
- True facts in a misleading frame :: accurate material presented out of context :: nothing false to correct, refutation requires explaining the context
- Impersonation of an official account :: a spoofed identity issuing instructions :: authority borrowed from a real institution, actionable by platforms immediately
PARAM: SPREAD MECHANISM
- Organic sharing by the public :: content people choose to pass on :: no coordination to disrupt, motivated by genuine belief
- Coordinated inauthentic network :: many controlled accounts :: detectable by behavioural signals, removable at the account level
- Amplification by mainstream media :: journalists repeating the claim :: enormous reach, correction possible through the same channel
- Closed encrypted messaging :: private groups forwarding content :: no visibility to any platform or researcher, no possibility of removal
PARAM: COUNTERMEASURE
- Rapid official rebuttal :: verified facts available quickly :: authoritative correction, risk of amplifying the original claim
- Platform content removal :: a policy basis and platform cooperation :: reduction of reach, ineffective where the content has already spread elsewhere
- Prebunking and media literacy :: time before the crisis :: durable resistance, no effect during an event already under way
- Do not engage :: a judgement that attention would amplify :: no amplification risk, no correction either
PARAM: EFFECT
- Claim contained :: refuted before wide belief :: no operational consequence
- Public confusion about instructions :: contradictory guidance in circulation :: reduced compliance with genuine advice
- Responder safety compromised :: false claims directing hostility at responders :: attacks on crews, withdrawal of services
- Lasting loss of institutional trust :: belief persisting after refutation :: reduced compliance in the next event

Organic sharing by the public >< Platform content removal | N7 | a policy basis and platform cooperation | no coordination to disrupt

DOMAIN: mass movement of people at a frontier
GROUP: migration
PARAM: MOVEMENT DRIVER
- Sudden armed conflict :: fighting reaching a populated area :: departure within hours, whole families, no preparation whatsoever
- Slow-onset environmental collapse :: land ceasing to support livelihoods :: movement over years, mostly working-age individuals
- Instrumentalised movement by a state :: a state facilitating arrivals to create pressure :: concentrated at one crossing, coordinated timing, a political rather than humanitarian origin
- Economic pull from a labour market :: demand for workers across the border :: continuous rather than spiked, responsive to enforcement and to wages
PARAM: FRONTIER TYPE
- Formal land crossing :: a road and an official post :: registration possible, processing capacity a hard limit
- Green border in remote terrain :: unfenced country :: no processing point at all, detection the only issue
- Maritime arrival by small boat :: a sea route and departure beaches :: rescue obligation engaged, arrival location unpredictable
- Airport transit zone :: arrival by air without entry :: identity documented on departure, a legally distinct space
PARAM: RECEPTION CAPACITY
- Registration and accommodation available :: sites and staff in place :: orderly processing, arrivals sheltered
- Processing backlog of months :: caseload far exceeding decision capacity :: prolonged limbo, informal settlements forming
- No reception system at all :: no legal framework or facilities :: arrivals unregistered, movement onward uncontrolled
- Onward transfer under an agreement :: a receiving third country and a legal basis :: transfer of the caseload, legal challenge likely
PARAM: OUTCOME
- Orderly registration and integration :: capacity matching arrivals :: no crisis
- Humanitarian conditions at the frontier :: people held with inadequate shelter :: illness and deaths, international attention
- Onward irregular movement :: arrivals continuing beyond the frontier :: pressure transferred to other states
- Frontier closure and pushback :: physical prevention of entry :: legal violation, people stranded on the far side

DOMAIN: armed drone incursion over national infrastructure
GROUP: security
PARAM: INCURSION PROFILE
- Single reconnaissance overflight :: one airframe transiting the site :: imagery collection only, no weapon carried, deniable as a navigation error
- Loitering munition strike :: an armed airframe with a target :: destruction of a specific asset, unambiguous attack
- Repeated harassment sorties :: sustained sorties over weeks :: no damage individually, cumulative operational and political effect
- Decoy incursion masking another axis :: cheap airframes drawing attention :: no effect at the site itself, defensive attention diverted
PARAM: PROTECTED SITE
- Nuclear power station :: a licensed nuclear site :: catastrophic consequence potential, extremely restricted airspace already
- Military airbase :: an operational air force installation :: organic air defence present, armed response available on site
- Offshore energy platform :: an installation far from any shore :: no ground-based defence within range, helicopter access only
- Urban government district :: government buildings in a populated area :: no kinetic engagement possible over the population, dense sensor coverage
PARAM: RESPONSE OPTION
- Kinetic engagement :: a clear firing solution and an acceptable backdrop :: certain destruction of the airframe, falling debris
- Electronic countermeasures :: the airframe depending on a link or on satellite navigation :: non-destructive defeat, interference with civil users nearby
- Track and do not engage :: sensors and a decision to observe :: intelligence gained, the incursion completes unimpeded
- Diplomatic and legal response :: attribution to a state or operator :: consequences after the event, no effect at the time
PARAM: OUTCOME
- Airframe defeated before the objective :: an effective engagement :: no damage, wreckage available for exploitation
- Objective achieved by the intruder :: no effective defence :: damage or imagery obtained
- Incursion undetected until afterwards :: no sensor coverage at the time :: awareness only from later evidence
- Collateral harm from the response :: a defensive action causing damage :: own-goal consequences, public and legal exposure
